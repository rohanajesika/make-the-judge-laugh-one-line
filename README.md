A program that writes one funny line — a barista asked for something strong, handing over her resignation letter instead of a coffee — to `/output/entry.txt`. One sentence, 80 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Make the Judge Laugh in One Line" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
